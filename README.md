## 🚧 What I'm building now

### 🌍 [Indigen World](https://github.com/pwavwef-web/indigen-world)

A cultural-technology ecosystem for indigenous-language preservation, cultural learning, storytelling
and creator participation. It brings together three products on shared Firebase and
provider-independent AI infrastructure:

- **Indigen World Website** — the public home for programmes, stories, communities and partnerships
- **TribeStudio** — the workspace for creators, contributors and validators
- **Indigen World Mobile** — a Flutter app to explore, learn, save and contribute

It starts with **Project Kassena**, a Kasem-language programme that proves a reusable model for adding
more language communities. Community consent, licensing and cultural permissions are treated as
infrastructure, not an afterthought.

## 🧠 How I like to build

- **Problem first, technology second.** A fancy stack cannot rescue a pointless product.
- **AI should be infrastructure, not decoration.** I care about reliability, grounding, evaluation and responsible product behaviour.
- **Ship, observe, improve.** I would rather test a real workflow than endlessly debate a perfect mock-up.
- **Design for ordinary people.** Good software should reduce cognitive load, not add another manual to someone's life.
- **Local context matters.** Products built for African users should not treat bandwidth, accessibility, language or institutional realities as edge cases.
